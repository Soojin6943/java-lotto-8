# java-lotto-precourse
**[프리코스 3주차]** **로또 발매기**를 구현하는 과제입니다.


해당 과제는 구입한 로또들의 당첨 내역과 수익률을 반환합니다. <br>
>사용자가 입력한 구입 금액에 따라 로또를 발행하고, <br>
당첨 번호와 보너스 번호를 입력받아 당첨 결과와 수익률을 계산합니다.

# 기능 목록
### 입출력 기능

- [ ]  로또 구입 금액 입력
- [ ]  당첨 번호(중복되지 않는 6개의 숫자) 입력
- [ ]  보너스 번호 1개 입력

- [ ]  로또 번호 출력 (오름차순 정렬)
- [ ]  발행한 로또 수량 출력
- [ ]  수익률 출력 (소수점 둘째 자리에서 반올림)
- [ ]  예외 상황 시 에러 문구 출력 (”[ERROR]”로 시작)

### 기본 기능

- [ ]  중복되지 않는 6개의 숫자 뽑기 (1개의 로또 발행)
- [ ]  로또 구매 금액에 해당하는 만큼 로또 발행
- [ ]  당첨 등수 구하기
- [ ]  수익률 구하기

### 예외처리

- [ ]  잘못된 값 입력 시 에러 IllegalArgumentException 발생
    - [ ]  `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.
    - [ ]  다시 입력 받기
