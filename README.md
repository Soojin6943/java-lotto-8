# java-lotto-precourse
**[프리코스 3주차]** **로또 발매기**를 구현하는 과제입니다.


해당 과제는 구입한 로또들의 당첨 내역과 수익률을 반환합니다. <br>
>사용자가 입력한 구입 금액에 따라 로또를 발행하고, <br>
당첨 번호와 보너스 번호를 입력받아 당첨 결과와 수익률을 계산합니다.

# 기능 목록
### 입출력 기능

- [X]  로또 구입 금액 입력
- [X]  당첨 번호(중복되지 않는 6개의 숫자) 입력
- [X]  보너스 번호 1개 입력
- [X]  잘못된 형식의 입력 시 다시 입력 받기

- [X]  로또 번호 출력 (오름차순 정렬)
- [X]  발행한 로또 수량 출력
- [X]  수익률 출력 (소수점 둘째 자리에서 반올림)
- [X]  예외 상황 시 에러 문구 출력 (”[ERROR]”로 시작)

### 기본 기능

- [X]  중복되지 않는 6개의 숫자 뽑기 (1개의 로또 발행)
- [X]  로또 구매 금액에 해당하는 만큼 로또 발행
- [X]  당첨 등수 구하기
- [X]  수익률 구하기

### 예외처리

- [X]  잘못된 값 입력 시 에러 IllegalArgumentException 발생
    - [X]  `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.
    - [X]  구입 금액이 1000원 단위가 아닌 경우
    - [X]  구입 금액이 1000원 미만인 경우
    - [X]  로또 번호가 6개가 아닌 경우
    - [X]  로또 번호에 중복이 있을 경우
    - [X]  로또 번호가 1~45 범위를 벗어날 경우
    - [X]  보너스 번호가 당첨 번호와 중복될 경우
    - [X]  보너스 번호 범위 오류
    - [X]  잘못된 문자열 입력 오류

# 실행 예시
```
구입 금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

# 패키지 구조
```
lotto
 ├── Application.java          // 프로그램 실행 시작점
 ├── controller
 │    └── LottoController.java // 전체 흐름 제어
 ├── model
 │    ├── Lotto.java           // 로또 한 장
 │    ├── LottoMachine.java    // 로또 자동 발행기
 │    ├── LottoResult.java     // 당첨 결과 및 수익률 계산
 │    ├── Rank.java            // 등수 Enum
 │    ├── Price.java           // 금액 검증 및 로또 개수 계산
 │    ├── Parser.java          // 입력값 파싱
 │    ├── WinningNumbers.java  // 당첨 번호 검증
 │    ├── BonusNumber.java     // 보너스 번호 검증
 │    └── WinningLotto.java    // 당첨 로또 정보(당첨+보너스)
 └── view
      ├── InputView.java       // 입력 담당
      └── OutputView.java      // 출력 담당

```
